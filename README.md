# MAC-Flow — Monetary Debasement and Equity Tail-Risk

Code for the paper:

> **Monetary Debasement and Equity Tail-Risk: Scenario Generation via Global/Local Conditioning on Macroeconomic Paths**

MAC-Flow is an autoregressive (AR) **Conditional Normalizing Flow** (RQ-NSF, Durkan et al. 2019; skew Student-t base, Hansen 1994) that generates 13-week-ahead S&P 500 return scenarios conditioned on **hypothetical paths** of the 3-month T-bill rate and an excess-liquidity indicator (M2 − INDPRO − CPI). The future path is injected through a **dual mechanism**: a Future Context Encoder that summarizes the whole path and broadcasts it to every generation step (*global*), and a per-step encoder that injects the path point by point (*local*). Tail risk is measured with the **intra-horizon loss** (worst cumulative loss within the holding period), which is order-sensitive and therefore path-dependent.

## Reproducing the paper (`notebooks/`)

The notebooks are meant to be run in order on Colab. `03`–`05` produce the checkpoints and caches; `01` re-aggregates the tables from those caches.

| Notebook | What it does | Needs |
|---|---|---|
| `01_reproduce_tables.ipynb` | Re-aggregates the §4 tables from the caches written by `02`–`05` — no training | caches |
| `02_inference_from_checkpoints.ipynb` | Re-runs inference from trained checkpoints and rebuilds the caches | checkpoints (GPU) |
| `03_train_macflow.ipynb` | Trains the main model, the path-condition / past-encoder ablations, and the M2-fill robustness model (4 folds × 5 seeds) | GPU |
| `04_baselines.ipynb` | Fits GARCH-ST and trains the Conditional VAE / GAN and MAC-VAE baselines | GPU |
| `05_hypothetical_paths.ipynb` | Runs the §4.3 hypothetical-path (shape) experiments | checkpoints (GPU) |

Seeds are fixed (`2026–2030`) and sampling uses paired seeds, so re-runs reproduce the reported numbers.

## Data

Raw series are public: FRED (`TB3MS`, `M2SL`, `INDPRO`, `CPIAUCSL`, `DCOILWTICO`), the Philadelphia Fed ADS index, and Yahoo Finance (S&P 500). We do not redistribute the raw data; `data/extend_to_1971.py` downloads and rebuilds the weekly dataset and the four walk-forward folds, with publication-lag alignment as described in §3.1 of the paper.
